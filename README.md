# Sungje Market Command Center Pro v6

Major features:

- 1D, 5D, 1M, 3M, 6M, YTD, 1Y and 5Y chart ranges
- MA20, MA50, MA100 and MA200
- Bollinger Bands, Volume, RSI and MACD
- 52-week high/low, volume ratio and period returns
- Market cap, P/E, EPS, dividend yield, beta and target price
- Earnings radar
- Charles Schwab OAuth connection
- Live balances and portfolio positions
- Portfolio AI Advisor with concentration and category analysis

Real Schwab credentials belong in Streamlit Cloud Secrets, never in GitHub.
